# 📊 HR Employee Attrition Analysis

## Project Overview

This project analyses employee attrition using SQL and Tableau to uncover patterns in employee turnover. The analysis focuses on identifying which departments and job roles experience the highest attrition and presents the findings through an interactive Tableau dashboard.

---

## Tools Used

- SQL (MySQL)
- Tableau Public
- Microsoft Excel

---

## Dataset

IBM HR Analytics Employee Attrition Dataset

- Total Employees: **1,470**
- Employees Who Left: **237**
- Attrition Rate: **16.1%**

---

## Business Questions

- What is the overall employee attrition rate?
- Which department experienced the highest attrition?
- Which job roles experienced the highest attrition?
- Which job roles had the most employees working overtime?
- Which job roles earned the highest average monthly income?
- Which department had the highest average job satisfaction?

---

## Key Findings

- Research & Development recorded the highest employee attrition.
- Laboratory Technicians experienced the highest employee turnover.
- Research Scientists had the highest number of employees working overtime.
- Managers earned the highest average monthly income.
- Sales recorded the highest average job satisfaction score.
